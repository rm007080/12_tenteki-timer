# 点滴タイマー 要件定義書

作成日：2026-05-06  
対象アプリ名：点滴タイマー  
対象バージョン：MVP v1.0

---

## 1. 目的

「点滴タイマー」は、現在接続している点滴バッグの残量、終了予定時刻、滴下係数を入力すると、自然滴下で調整するための目安を即時計算する個人利用向けスマホアプリである。

本アプリは、以下の3つを主目的とする。

1. 現在バッグの残量と終了予定時刻から、必要な滴下速度をすぐ算出する。
2. 滴下係数 15滴/mL、20滴/mL、60滴/mL の違いに対応する。
3. 点滴速度が途中で速くなったり遅くなったりした場合に、再計算を素早く行えるようにする。

---

## 2. 前提・注意事項

本アプリは、医療行為そのものを判断するためのアプリではなく、自然滴下の計算補助を目的とする。

以下の判断や業務を代替しない。

- 医師の指示
- 施設の運用ルール
- 看護師・医療従事者による確認
- 輸液ポンプ設定
- 薬剤投与量の判断
- 薬剤濃度計算
- 体重換算
- 小児などの詳細な投与設計

---

## 3. 対象範囲

### 3.1 対象とするもの

- クレンメで調整する自然滴下
- 現在接続している点滴バッグ1本分の計算
- mL/h、滴/分、秒/滴の目安計算
- iPhone / Android のスマホ利用
- GitHub Pagesで公開し、ホーム画面に追加して使うPWA
- 完全オフライン利用

### 3.2 対象外とするもの

- 輸液ポンプ設定
- 薬剤濃度計算
- 体重換算
- mg/kg/min、μg/kg/min などの投与量計算
- 患者名、部屋番号、患者IDなどの個人情報管理
- 計算履歴の保存
- リアルタイムのカウントダウンタイマー
- 通知機能
- ストア公開

---

## 4. 利用者

主な利用者は、個人のスマホで自然滴下の計算補助を行いたいユーザーである。

本アプリは公式公開用ではなく、個人利用を前提とする。ただし、GitHub Pagesで公開するため、URLを知っている人はアクセス可能な状態でもよい。

---

## 5. 利用シーン

### 5.1 基本利用

ユーザーは、現在接続されている点滴バッグについて、以下を入力する。

- 現在バッグの残量
- 終了予定時刻
- 滴下係数

アプリは、スマホの現在時刻を自動取得し、終了予定時刻までの残り時間を算出する。そのうえで、以下を表示する。

- 約○秒に1滴
- ○滴/分
- ○mL/h

### 5.2 複数本の点滴がある場合

例：500mLが2本あり、合計24時間で落としたい場合。

本アプリでは、複数本を合計量として計算しない。1本ごとに計算する。

例：500mL × 2本を24時間で落とす場合は、以下のように扱う。

- 1本目：500mLを12時間で落とす
- 2本目：500mLを12時間で落とす

ただし、本数ごとの時間配分はアプリが自動計算しない。ユーザーが、現在バッグの終了予定時刻を自分で入力する。

## 6. 入力要件

### 6.1 残量

| 項目 | 内容 |
|---|---|
| 入力対象 | 現在接続している点滴バッグの残量 |
| 単位 | mL |
| 入力方法 | 数字を直接入力 |
| 入力刻み | 10mL単位として扱う |
| 小数入力 | 許可する |
| 10mL単位でない場合 | 10mL単位に四捨五入する |
| 最小値 | 丸め後10mL以上 |
| 最大値 | 丸め後2500mL以下 |

#### 残量の丸め例

| 入力値 | 計算に使用する値 |
|---:|---:|
| 123mL | 120mL |
| 125mL | 130mL |
| 126mL | 130mL |
| 123.5mL | 120mL |
| 125.5mL | 130mL |
| 2504mL | 2500mL |
| 2505mL | 2510mL → エラー |

#### 残量エラー

| 条件 | エラーメッセージ |
|---|---|
| 空欄 | 残量を入力してください |
| 丸め後が0mL以下 | 残量は10mL以上で入力してください |
| 丸め後が2500mL超 | 残量は2500mL以下で入力してください |

エラーは、残量入力欄の近くに表示する。

---

### 6.2 終了予定時刻

| 項目 | 内容 |
|---|---|
| 入力対象 | 現在バッグを終わらせたい時刻 |
| 表記 | 24時間表記 |
| 入力UI | スマホ標準の時刻入力 |
| 入力例 | 08:00、13:30、20:00 |
| 入力刻み | 10分単位として扱う |
| 10分単位でない場合 | 近い10分単位に四捨五入する |

#### 終了予定時刻の丸め例

| 入力値 | 計算に使用する時刻 |
|---|---|
| 08:14 | 08:10 |
| 08:15 | 08:20 |
| 08:17 | 08:20 |

#### 終了予定時刻の当日・翌日判定

終了予定時刻は、まず10分単位に丸める。丸め後の時刻で、当日か翌日かを判定する。

| 丸め後の終了予定時刻 | 判定 |
|---|---|
| 現在時刻より後 | 当日の終了予定時刻として扱う |
| 現在時刻より前 | 翌日の終了予定時刻として扱う |
| 現在時刻と同じ | 翌日の同時刻として扱う |

例：

| 現在時刻 | 入力 | 丸め後 | 判定 |
|---|---|---|---|
| 08:16 | 08:15 | 08:20 | 今日08:20 |
| 08:20 | 08:17 | 08:20 | 翌日08:20 |
| 20:00 | 08:00 | 08:00 | 翌日08:00 |

#### 終了予定時刻エラー

| 条件 | エラーメッセージ |
|---|---|
| 空欄 | 終了予定時刻を入力してください |

エラーは、終了予定時刻入力欄の近くに表示する。

---

### 6.3 滴下係数

| 項目 | 内容 |
|---|---|
| 選択肢 | 15滴/mL、20滴/mL、60滴/mL |
| 入力方法 | ボタンで選択 |
| 初期選択 | 20滴/mL |
| カスタム入力 | 初期版では対応しない |
| 前回選択値の保持 | しない |

アプリ起動時および計算後のリセット時は、20滴/mLが選択された状態に戻る。

---

### 6.4 現在時刻

| 項目 | 内容 |
|---|---|
| 取得方法 | スマホの現在時刻を自動取得 |
| 基準 | 「計算する」ボタンを押した瞬間 |
| 精度 | 時・分まで使用 |
| 秒 | 切り捨てて無視 |

例：

| 実時刻 | 計算に使用する現在時刻 |
|---|---|
| 13:07:45 | 13:07 |

---

## 7. 出力要件

### 7.1 表示項目

計算結果は、以下の順番で表示する。

1. 約○秒に1滴
2. ○滴/分
3. ○mL/h

「約○秒に1滴」を最も大きく表示する。  
「滴/分」は次に目立つように表示する。  
「mL/h」は補助情報として表示する。

表示例：

```text
約4秒に1滴

14滴/分
42mL/h
```

---

### 7.2 mL/hの表示

| 項目 | 内容 |
|---|---|
| 表示形式 | 整数 |
| 丸め方 | 四捨五入 |
| 例 | 41.7mL/h → 42mL/h |
| 例 | 41.3mL/h → 41mL/h |

ただし、内部計算上は0ではないが、四捨五入すると0mL/hになる場合は、以下のように表示する。

```text
1mL/h未満
```

---

### 7.3 滴/分の表示

| 項目 | 内容 |
|---|---|
| 表示形式 | 整数 |
| 丸め方 | 四捨五入 |
| 例 | 13.9滴/分 → 14滴/分 |
| 例 | 13.4滴/分 → 13滴/分 |

ただし、内部計算上は0ではないが、四捨五入すると0滴/分になる場合は、以下のように表示する。

```text
1滴/分未満
```

この場合、「約○秒に1滴」は表示しない。

---

### 7.4 秒/滴の表示

「約○秒に1滴」は、表示用に四捨五入された整数の滴/分をもとに計算する。

計算式：

```text
秒/滴 = 60 ÷ 表示用の滴/分
```

表示形式は整数とし、四捨五入する。

例：

| 内部計算 | 表示用 滴/分 | 秒/滴計算 | 表示 |
|---:|---:|---:|---|
| 13.9滴/分 | 14滴/分 | 60 ÷ 14 = 4.28... | 約4秒に1滴 |
| 8.4滴/分 | 8滴/分 | 60 ÷ 8 = 7.5 | 約8秒に1滴 |

滴/分が「1滴/分未満」の場合、秒/滴は表示しない。

---

### 7.5 条件表示

メイン結果の下に、計算に使用した条件を小さく表示する。

表示する条件は以下である。

- 残量
- 終了予定時刻
- 残り時間
- 滴下係数

表示例：

```text
条件：残量500mL / 終了20:00 / 残り12時間00分 / 20滴/mL
```

計算時刻は表示しない。  
計算式や計算根拠は表示しない。  
残量や終了予定時刻が丸められた場合は、丸め後の値だけを条件欄に表示する。

---

## 8. 計算要件

### 8.1 基本式

```text
残り時間分 = 終了予定日時 - 現在日時
mL/h = 残量mL ÷ 残り時間分 × 60
滴/分 = 残量mL ÷ 残り時間分 × 滴下係数
秒/滴 = 60 ÷ 表示用の滴/分
```

### 8.2 計算順序

1. 「計算する」ボタンを押す。
2. スマホの現在時刻を取得する。
3. 現在時刻の秒を切り捨てる。
4. 残量を取得する。
5. 残量を10mL単位に四捨五入する。
6. 丸め後の残量が10mL以上2500mL以下か確認する。
7. 終了予定時刻を取得する。
8. 終了予定時刻を10分単位に四捨五入する。
9. 丸め後の終了予定時刻で、当日・翌日を判定する。
10. 残り時間を分単位で計算する。
11. mL/hを計算し、整数表示にする。
12. 滴/分を計算し、整数表示にする。
13. 表示用の滴/分から秒/滴を計算し、整数表示にする。
14. 結果と条件を表示する。
15. 入力欄をリセットする。

## 9. 画面要件

### 9.1 画面構成

1画面で完結させる。

- 入力欄
- 滴下係数ボタン
- 計算ボタン
- 結果表示エリア
- 条件表示エリア

画面遷移は行わない。

### 9.2 表示イメージ

```text
点滴タイマー

現在バッグの残量
[ 500 ] mL

終了予定時刻
[ 20:00 ]

滴下係数
[ 15 ] [ 20 ] [ 60 ]

[ 計算する ]

----------------

約4秒に1滴

14滴/分
42mL/h

条件：残量500mL / 終了20:00 / 残り12時間00分 / 20滴/mL
```

### 9.3 テーマ

スマホ本体の設定に合わせて、ライトモードとダークモードを自動切り替えする。

- ライトモード：白系背景、黒系テキスト
- ダークモード：黒または濃紺系背景、白系テキスト

アプリ内にテーマ切り替えボタンは設けない。

## 10. 操作要件

### 10.1 計算実行

- 入力中に自動計算しない。
- 「計算する」ボタンを押したときだけ計算する。
- 計算ボタン押下時点の現在時刻を基準にする。

### 10.2 計算後のリセット

計算成功後、入力欄はリセットする。

- 残量入力は空欄に戻す。
- 終了予定時刻は空欄に戻す。
- 滴下係数は20滴/mLに戻す。
- 計算結果は画面に残す。

### 10.3 計算結果の保持

- 計算結果は、次に正常計算するまで画面に残す。
- 新しい計算が成功した場合のみ、結果を上書きする。
- エラーが発生しても、前回の結果は消さない。
- アプリを開き直した場合、前回の結果は保持しない。

---

## 11. エラー表示要件

エラーは、該当する入力欄の近くに表示する。画面上部にまとめて表示しない。

| エラー条件 | 表示位置 | メッセージ |
|---|---|---|
| 残量が空欄 | 残量入力欄の近く | 残量を入力してください |
| 丸め後の残量が0mL以下 | 残量入力欄の近く | 残量は10mL以上で入力してください |
| 丸め後の残量が2500mL超 | 残量入力欄の近く | 残量は2500mL以下で入力してください |
| 終了予定時刻が空欄 | 終了予定時刻入力欄の近く | 終了予定時刻を入力してください |

初期版では、極端な滴下数や流量に対する警告は出さない。計算できる値であれば、そのまま結果を表示する。

---

## 12. プライバシー要件

本アプリは、個人情報を扱わない。

入力しない情報：

- 患者名
- 部屋番号
- 患者ID
- 診療情報
- メモ

保存しない情報：

- 残量
- 終了予定時刻
- 滴下係数の選択履歴
- 計算結果
- 計算履歴

外部送信しない情報：

- すべての入力値
- 計算結果
- 利用履歴

localStorageなどを使った永続保存は行わない。

---

## 13. PWA・オフライン要件

本アプリはPWAとして実装する。

- GitHub Pagesで公開する。
- 初回アクセス後、スマホのホーム画面に追加して使えるようにする。
- 初回読み込み後は、通信がない場所でも使えるようにする。
- 計算処理はすべて端末内で完結する。
- 外部APIは使用しない。

## 15. MVP完了条件

MVP v1.0は、以下を満たしたら完了とする。

- スマホで1画面の計算UIが使える。
- 残量、終了予定時刻、滴下係数を入力できる。
- 現在時刻を自動取得できる。
- 終了予定時刻の日付またぎに対応できる。
- 残量を10mL単位に丸められる。
- 終了予定時刻を10分単位に丸められる。
- mL/h、滴/分、秒/滴を計算できる。
- 結果を指定順で表示できる。
- 条件欄を小さく表示できる。
- エラーを入力欄の近くに表示できる。
- 計算成功後に入力欄をリセットできる。
- 前回結果を次の正常計算まで保持できる。
- アプリ再起動後は前回結果を保持しない。
- PWAとしてホーム画面に追加できる。
- 初回読み込み後にオフライン利用できる。
- iPhone / Androidの両方で利用できる。
