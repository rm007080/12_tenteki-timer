# 秒針ガイド機能追加チェックリスト

## 概要

- 計算成功後だけ、結果パネル下部にアナログ秒針ガイドを表示する。
- 計算前は秒針エリアを表示しない。
- 秒針は端末の現在秒に同期し、1秒ごとに刻む。
- 開始/停止ボタンは作らない。
- ガイドは「計算成功時の時刻」を基準に、`約N秒に1滴` のN秒間隔で動く。
- 現在秒針から次の目印までを色付き範囲で示す。
- 2つ先の目印は破線で控えめに表示する。
- 読ませる線は3:1以上のコントラストを保つ。
- 計算成功後は結果パネルへ自動スクロールし、主結果、滴/分、mL/h、条件、秒針ガイドが同じ流れで見える位置に移動する。
- 秒針ガイドはカウントダウンタイマーではなく、滴下間隔を目視で合わせるための補助表示として扱う。
- 入力変更後や入力エラー時は、表示中の結果とガイドが「前回の計算結果」であり、新しい入力はまだ反映されていないことを画面上に表示する。

## 前提と対象外

- 秒針ガイドは医療判断の代替ではなく、既存の注意文言と同じ前提で扱う。
- 数値カウントダウンは出さない。
- 画面維持は今回の範囲外とする。
- 音は今回の範囲外とする。
- 通知は今回の範囲外とする。
- バイブレーションは今回の範囲外とする。
- Wake Lockは今回の範囲外とする。
- 滴下速度の計算自体は既存要件どおり分単位で行う。
- 秒針ガイドだけが、目視補助として秒境界に丸めた現在時刻を使う。
- 計算結果は永続保存しない。
- 入力値は永続保存しない。
- 秒針ガイド状態は永続保存しない。
- Service WorkerのCache APIはアプリ本体ファイルのオフライン利用に限って使う。
