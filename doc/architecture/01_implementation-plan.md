# 点滴タイマー 実装チェックリスト

## 概要

自然滴下の残量と終了予定時刻から、`mL/h`、`滴/分`、`秒/滴` の目安を計算する個人利用向けPWAを実装する。

正本は次の3文書とする。

- [../../specs/requirements.md](../../specs/requirements.md)
- [overview.md](overview.md)
- [tech-stack.md](tech-stack.md)

## 前提と制約

- HTML / CSS / JavaScript のみで実装する。
- React、ビルドツール、外部API、DB、ユーザーデータ保存APIは追加しない。
- ユーザー入力値、計算結果、利用履歴は永続保存しない。
- Cache APIはService Workerがアプリ本体ファイルをオフライン利用する目的に限って使用する。
- 計算ロジックはDOMから分離し、固定した `now` を渡してテストできる形にする。
- GitHub Pagesの公開元はリポジトリルートとし、アプリURLは `/<repo>/app/src/` とする。
- GitHub Actionsで別ディレクトリへ再配置する手順はMVPでは作らない。
- `app/src/` 配下で動くように、PWA設定は相対パスに固定する。
- UIには「自然滴下の計算補助です。指示・施設ルールに従って確認してください。」を表示する。

## ファイル構成

```text
app/
├── src/
│   ├── index.html
│   ├── style.css
│   ├── calc.js
│   ├── app.js
│   ├── manifest.json
│   ├── service-worker.js
│   └── icons/
│       ├── icon-192.png
│       └── icon-512.png
└── tests/
    └── calculation-test.html
```

- `calc.js` はDOMを触らず、`window.TentekiCalc` に純粋関数を公開する。
- `app.js` はDOM操作とイベント処理だけを担当し、計算は `window.TentekiCalc.calculate()` を呼び出す。
